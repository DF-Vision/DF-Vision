# Archived session logs

These files (`MORNING_HANDOFF.md`, `MORNING_HANDOFF_2.md`,
`MORNING_HANDOFF_3.md`, `MORNING_HANDOFF_4.md`, `OVERNIGHT_LOG.md`,
`PROJECT_STATUS.md`) are per-session status/handoff documents from
earlier in this project. Their content is superseded by the consolidated
documents below — read those for current state; read these only for
full historical/chronological detail:

- `project_final/PROJECT_STATUS_FINAL.md` — supersedes this folder's
  `PROJECT_STATUS.md` (its per-contribution sections).
- `project_final/PRG_SIGNAL_STATUS.md` — supersedes this folder's
  `MORNING_HANDOFF_3.md` and `MORNING_HANDOFF_4.md` (PRG-related content).

Moved here (2026-09-28, repo cleanup) from the repo root, via `git mv`,
so history is preserved (`git log --follow <file>` still works). Content
is unchanged. Other files in this project still reference these by their
old root-level path (e.g. `PROJECT_STATUS.md` rather than
`archive/session_logs/PROJECT_STATUS.md`) — those are historical
documents in their own right and are not rewritten for this move, per
this project's own discipline of treating past session records as a
frozen, append-only account of what was true when they were written.
